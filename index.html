HTTP API (the version the judge calls)

This page runs the bot's composer and conversation handler directly in your browser. The graded version is the same code behind a FastAPI server (bot.py), which must be hosted somewhere that can run Python (Render, Railway, a VM, or a tunnel from a laptop). GitHub Pages can only serve static files.

EndpointWhat it does
POST /v1/contextStores a category, merchant, customer or trigger context, versioned. The same or an older version returns 409.
POST /v1/tickGoes through the active triggers by urgency and returns composed messages, deduplicated and capped per merchant.
POST /v1/replyTakes a merchant or customer reply and returns send, wait or end.
GET /v1/healthzLiveness check plus the count of contexts loaded.
GET /v1/metadataTeam, model and approach.

Run it: pip install fastapi uvicorn pydantic then uvicorn bot:app --host 0.0.0.0 --port 8080. Interactive API docs are then at /docs.
